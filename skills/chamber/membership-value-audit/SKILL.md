# Membership Value Audit

Connect Chamber participation to the business's real goals without treating membership as a passive badge.

Clarify the business, customers, current membership status, annual goals, existing Chamber activity, time budget, relationship strengths, and desired outcomes. Choose no more than three measurable 90-day outcomes such as relevant introductions, supplier discoveries, partner conversations, learning, visibility, or community contribution.

If Chamber MCP is available, check snapshot freshness, then:

- search events that align with the goals;
- search member categories for customers, suppliers, peers, referral partners, and experts;
- inspect benefits or deals only when reliable tools return data;
- retrieve records and retain source URLs.

Never imply that a member attends an event, will accept an introduction, is endorsed, or is a good fit beyond sourced information. Search ranking is not quality. If MCP is unavailable, work from the Chamber's current public directory and event links supplied by the user.

Create a 90-day participation portfolio with:

1. selected events and purpose for each;
2. relationship categories to understand—not a spam list;
3. a give-first contribution the business can make;
4. pre-event preparation and post-event follow-up;
5. a simple contact/commitment log;
6. monthly time budget;
7. leading indicators and business outcomes;
8. a renewal review that includes qualitative value and opportunity cost.

Separate sourced Chamber information from generated strategy. Include snapshot date and original links, state that Chamber membership is not an endorsement or quality rating, and end with next actions for this month.
